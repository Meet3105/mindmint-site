# mindmint.co.in — Official Website

Digital Service Studio, Useful Digital Products & Financial Advisory (`work@mindmint.co.in`).

## Repository Structure
- `index.html` — Complete, self-contained responsive website (HTML + Tailwind CSS + Interactive JS).
- `mindmint-logo.svg` — 1:1 square (512x512) brand emblem.
- `README.md` — Project setup and commit instructions.

## Deploying to GitHub Pages
1. Open your GitHub repository **Settings** > **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then click **Save**.

## Making Future Changes
- **Via GitHub Web UI:** Open `index.html`, click the **Edit (pencil)** icon, update text/links, and click **Commit changes**.
- **Via Git CLI:**
  ```bash
  git add index.html
  git commit -m "Describe your update"
  git push origin main
  ```
