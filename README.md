# Mindmint — Coming Soon

A responsive, framework-free landing page for Mindmint. The site is made with plain HTML, CSS and JavaScript, so you can upload it directly and build on it later.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive layout, colors and illustration
- `script.js` — current year and a small return-home interaction

## Upload these files to GitHub

1. Open [Meet3105/mindmint-site](https://github.com/Meet3105/mindmint-site).
2. Choose **Add file → Upload files**.
3. Unzip the download on your computer.
4. Upload `index.html`, `styles.css`, `script.js`, and `README.md` from the unzipped folder into the repository’s top level (do not upload the ZIP itself).
5. Add a commit message such as `Add Mindmint coming soon website`, then choose **Commit changes**.

Keep `index.html` at the repository top level so GitHub Pages can find it.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, set the source to **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**, then select **Save**.
4. Wait for the Pages deployment to finish. The site URL will appear in the Pages settings; for this repository it is typically `https://meet3105.github.io/mindmint-site/`.

## Make it yours

Edit the headline and description in `index.html`; adjust the colors, spacing and mobile styles in `styles.css`. The page uses Google Fonts when a visitor is online and falls back to system fonts when they are not.
